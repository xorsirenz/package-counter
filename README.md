# package-counter
GNOME shell extension that displays the number of package updates

#### current package managers supported:
- dnf
- apt
- pacman

### installation
```sh
$ git clone https://github.com/xorsirenz/package-counter.git
$ cd package-counter/
$ npm install
```
#### After installing the extension, you will need to restart the GNOME shell environment.
- X11: `Alt+F2` -> `r` -> `Enter`
- Wayland requires a full relog.
